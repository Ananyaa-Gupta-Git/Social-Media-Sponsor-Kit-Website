IISC 2026 Social Media Card Generator

FILES
- index.html: the interactive generator
- poster.jpg: your original poster artwork

QUICK TEST
1. Keep index.html and poster.jpg together in the same folder.
2. Double-click index.html to open it in Chrome, Edge, or Firefox.
3. Upload a photo, enter name/designation/organization, and click Download my card (PNG).

TO PUBLISH AS A WEBSITE
Upload both files to a static hosting service such as GitHub Pages or Netlify. Keep poster.jpg beside index.html.
No server-side code is required; photo processing and PNG export happen in the browser.

NOTES
- This is a starter version. Review the positioning and text size with several real names before sharing widely.
- The source artwork is used as the background, with editable fields drawn over the placeholder area.
